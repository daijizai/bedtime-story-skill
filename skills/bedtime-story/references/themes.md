# 题材种子

按需要选取和变化，不机械照搬。先决定用户的题材范围，再从地点、身份、关系、目标、事件中组合；同一灾难也应产生不同生活处境。

| 题材 | 可变化的起点 |
|---|---|
| 暴雪 | 山间夜班电台收到失联列车的呼叫；海边居民楼停暖，你与邻居整理公共厨房 |
| 沙暴 | 沙漠观测站等待换班；小镇书店打烊时沙墙逼近 |
| 洪水 | 旧城区楼顶搭起临时渡口；河边旅馆的住客共同搬运旧照片 |
| 极热 | 夜间才运行的城市交通；社区冷藏库出现一份需要送达的包裹 |
| 地震 | 震后的山城旅社相互照应；小岛码头等待恢复通信 |
| 辐射 | 地下聚落维修员寻找仍在广播的气象站；隔离区边缘的温室收到来信 |
| 丧尸 | 封闭公寓里维持一间小厨房；缓慢航行的渡轮寻找可停靠的港口 |
| 仙侠 | 雨夜山门的值夜弟子；浮空集市的修伞人；灵植园里一株只在深夜开花的草 |
| 都市 | 末班地铁的失物；深夜面包店的新邻居；老街修理铺的一台收音机 |
| 校园 | 雨后图书馆的借书卡；天文社夜间观测；毕业前整理旧社团活动室 |
| 其他 | 海上奇幻、历史旅途、太空日常、童话、轻悬疑等，按用户设定构建 |

适度互动的问题应落在已经发生的事上，例如“电台里有两个声音，你想先联系列车，还是先确认山下的避难站？”不要未讲故事就连问身份、背包、天气、路线。
