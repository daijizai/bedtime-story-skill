# 睡前沉浸故事 · Bedtime Story

一个以沉浸讲述为主的中文故事 Skill。支持灾难、仙侠、都市、校园和自定义题材，既能随机选题，也能指定具体场景；可在主讲与适度互动之间随时切换。

## 使用

将 `skills/bedtime-story` 整个目录复制到支持 SKILL.md 的宿主的技能目录。Codex 可放到 `~/.codex/skills/bedtime-story`，重新打开会话后调用 `$bedtime-story`。也可直接把 SKILL.md 内容交给聊天 AI 作为故事规则；自动发现、语音与上下文长度取决于宿主。

示例：

- `$bedtime-story 今晚全随机，你主讲，直接开始。`
- `$bedtime-story 随机一个灾难，适度互动，不要丧尸。`
- `$bedtime-story 暴雪，山间旅馆，主讲，慢一点。`
- `$bedtime-story 仙侠，我是看守灵植园的弟子，适度互动。`
- `$bedtime-story 校园日常，不要恋爱，你主讲。`
- `互动少一点，你继续讲。`
- `我困了，慢慢收尾。`
- `给我一个存档，明晚接着讲。`

只说“讲个故事”时，Skill 会用一句话询问题材和互动偏好；说“随便，直接讲”则随机选题并使用主讲模式。

## 模式

| 模式 | 体验 |
|---|---|
| 主讲 | 默认每轮约 900–1500 中文字，连续推进场景，不固定追问 |
| 适度互动 | 默认先讲约 600–1000 字，在有意义的节点问一个问题，可自由回答 |

长度可调整，不保证精确收听时长。随机可以限定在灾难类中，也可以跨题材；暴雪、沙暴、洪水、辐射、丧尸等只是可选主题的一部分。

## 续接与边界

通过当前对话维持剧情状态；跨会话可复制存档继续，不承诺自动记住过去每一晚。默认舒缓、轻度悬念，可调整紧张程度。此项目提供叙事指令，不包含语音引擎、自动播放或睡眠监测，也不需要 API 密钥。
