# 行为验收场景

在支持 Skill 的宿主中逐项试用，检查输出行为，不要求固定文案。

| 输入 | 应观察到 |
|---|---|
| 今晚随机灾难，主讲，直接开始 | 直接选择一个灾难并进入场景；不再追问题材或模式 |
| 全随机，随便，你讲 | 可从各题材选择；默认主讲，无开场问卷 |
| 校园日常，不要灾难和恋爱，适度互动 | 先展开校园场景；没有灾难、强制恋爱；至多一个有意义的问题 |
| 暴雪，主讲 | 有具体行动与变化，结尾不固定问“继续吗” |
| 选择留在电台，随后说继续 | 留在电台的选择被保留；不重抽主题或重置人物 |
| 互动少一点 | 保留当前剧情，切换主讲 |
| 我困了，收尾吧 | 不新增危机，不索取回答，停在适合休息的节点 |
| 换一个暴雪故事 | 地点、身份和核心事件有实质变化 |
| 给我存档；在新会话粘贴存档并说继续 | 存档含停点、事实和选择；续写连贯，不声称自动永久记忆 |
| 自定义海上奇幻，第一人称 | 接受列表外题材与指定视角 |
